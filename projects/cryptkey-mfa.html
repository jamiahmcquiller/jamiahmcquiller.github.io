CryptKey — MFA Application

Python | Flask | Authentication | Application Security

Project Overview

CryptKey is a security-focused application developed with Python and Flask to explore authentication workflows and multi-factor authentication concepts. The project provides an opportunity to apply programming skills to an application with security-focused requirements.

Project Goals

  • Design a clear authentication user experience.
  • Explore account creation and login workflows.
  • Investigate how additional authentication factors can strengthen account security.
  • Identify application security considerations and limitations.
  • Test expected and unexpected user interactions.

Technologies

  • Python: Application logic and backend development.
  • Flask: Web application framework.
  • HTML and CSS: User interface and page styling, where implemented.

Application Design

Authentication Workflow

The intended workflow includes account access and authentication-related interactions. The final implementation should clearly distinguish between features that work, features that are simulated, and features that remain incomplete.

Account Handling

Account creation, existing-account detection, credential validation, and persistence should be evaluated as separate requirements. Persistent account storage must be implemented and tested before claiming that user accounts survive application restarts.

Multi-Factor Authentication

Document the additional authentication factor actually implemented, if any. If MFA is currently a design goal rather than a working feature, identify it as planned functionality rather than completed protection.

Testing and Validation

  • Test valid and invalid login attempts.
  • Test account creation and duplicate-account handling.
  • Verify whether account data persists as intended.
  • Test input validation and error handling.
  • Document the status of MFA and other security controls.

Security Considerations

  • Use appropriate password hashing rather than storing plaintext passwords.
  • Protect sessions and authentication secrets.
  • Validate user input and handle errors safely.
  • Keep credentials and secrets out of source control.

Lessons Learned

Authentication applications require more than a login screen. Account lifecycle management, persistent storage, secure credential handling, session management, and thorough testing are important parts of building a dependable authentication system.
